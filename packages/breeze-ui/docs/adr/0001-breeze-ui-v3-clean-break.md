# Replace Breeze UI with a clean v3 release

Status: superseded by [ADR 0005](0005-breeze-ui-v4-clean-break.md).

This ADR records the earlier decision to retain the `@motech-development/breeze-ui` package identity while replacing its legacy API in a major release. The equivalent v4 clean break, including its current design rationale and consumer status, is recorded in [ADR 0005](0005-breeze-ui-v4-clean-break.md).
