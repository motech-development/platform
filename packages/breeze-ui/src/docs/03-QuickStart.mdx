# Quick start

Keep application state outside the library. A Button reports an activation through `onAction`, while the application controls `loading`.

```tsx
import { useState } from 'react';
import { BreezeProvider, Button } from '@motech-development/breeze-ui';
import '@motech-development/breeze-ui/styles.css';

export function SaveAction({ save }: { save: () => Promise<void> }) {
  const [loading, setLoading] = useState(false);

  async function handleSave() {
    setLoading(true);
    try {
      await save();
    } finally {
      setLoading(false);
    }
  }

  return (
    <BreezeProvider locale="en-GB">
      <Button loading={loading} onAction={handleSave}>
        Save changes
      </Button>
    </BreezeProvider>
  );
}
```

Handle success and errors in the application's flow. Use `type="submit"` inside a form when submission is the intended action. Use `variant="secondary"` for alternatives and `variant="danger"` for destructive actions.
