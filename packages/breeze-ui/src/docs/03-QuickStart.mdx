# Quick start

Set up Breeze at your application root so its components share the same locale, typography and visual language across pages and features.

## Set up your application

Import the stylesheet once in your entry point and wrap your application with `BreezeProvider`. Choose the locale used by your application.

```tsx
import { BreezeProvider } from '@motech-development/breeze-ui';
import { createRoot } from 'react-dom/client';
import { App } from './App';
import '@motech-development/breeze-ui/styles.css';

const root = document.getElementById('root');

if (root) {
  createRoot(root).render(
    <BreezeProvider locale="en-GB">
      <App />
    </BreezeProvider>,
  );
}
```

`App` is your application's root component. Keep the provider above the pages and features that use Breeze; individual components do not need their own provider.

## Build your interface

Use the component pages to choose the right elements for each task. Each page explains the component's purpose, supported options, interaction and accessibility requirements, with examples you can explore before using it.

Compose Breeze components with your application's content and layout. Use their documented props to select appearance and behaviour; styles and interaction details are handled by the library. Keep routing, data fetching, validation and business rules in your application, passing the relevant state and callbacks to components.

## Check the complete experience

Review your pages with realistic content, keyboard navigation and both colour schemes. Give controls clear labels, preserve visible focus, and make loading, success and error states understandable in the context of the user's task.

See <a href="./?path=/docs/guides-04-provider-and-styles--docs" target="_top">Provider and styles</a> for locale and colour-scheme setup, and <a href="./?path=/docs/guides-06-accessibility--docs" target="_top">Accessibility</a> for guidance on accessible use.
