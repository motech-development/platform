# Installation

Breeze requires React and React DOM 19. Add the package to your application:

```sh
yarn add @motech-development/breeze-ui
```

Import the compiled stylesheet once in your application entry point:

```tsx
import '@motech-development/breeze-ui/styles.css';
```

Then follow the <a href="./?path=/docs/guides-03-quick-start--docs" target="_top">Quick start</a> to set up Breeze across your application.

## Optional normalization

If you want Breeze's additional normalization, import `reset.css` before `styles.css`:

```tsx
import '@motech-development/breeze-ui/reset.css';
import '@motech-development/breeze-ui/styles.css';
```

Both stylesheets scope their visual rules to the Breeze root. Your application owns its document and body reset, page layout and background.

## Included styles

Breeze ships compiled styles, so your application needs no Tailwind setup or source scanning. Public Sans Latin is bundled with its licence and uses a system fallback while loading, without an external font request.

The stylesheet entry points are `styles.css` and `reset.css`. Use documented component options to customise your interface; CSS variables are private implementation details.
