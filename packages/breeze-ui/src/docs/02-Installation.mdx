# Installation

Run the following command to add Breeze UI to your application:

```sh
yarn add @motech-development/breeze-ui
```

## Peer dependencies

`react` and `react-dom` are peer dependencies. Breeze UI requires React 19.

## Styles

Import the stylesheet once, at the entry point of your application:

```tsx
import '@motech-development/breeze-ui/styles.css';
```

## Reset

Breeze UI provides an optional reset for browser default styles. To use it, import it before the stylesheet:

```tsx
import '@motech-development/breeze-ui/reset.css';
import '@motech-development/breeze-ui/styles.css';
```
