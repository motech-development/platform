# Installation

Use the v4 release of `@motech-development/breeze-ui` with stable React and React DOM 19. This repository uses Yarn 4 and semantic-release; the package's development placeholder is replaced at release time. The foundation is a breaking release, not an upgrade path for the old component API.

Import the required compiled stylesheet once, before rendering the provider:

```tsx
import '@motech-development/breeze-ui/styles.css';
import { BreezeProvider, Button } from '@motech-development/breeze-ui';

export function App() {
  return (
    <BreezeProvider locale="en-GB">
      <Button>Save changes</Button>
    </BreezeProvider>
  );
}
```

An application that wants Breeze's additional scoped normalization can import `reset.css` before `styles.css`. Both remain inside `[data-breeze-root]`; the application owns its document/body reset and background.

Consumers need no Tailwind setup, scanning, plugins or version alignment. Public Sans Latin is bundled with its licence and uses system fallback while loading. There is no external font request.

The only stylesheet entry points are `styles.css` and `reset.css`. `theme.css` and the former icon subpath are removed. CSS variables are private implementation details; do not override them.
