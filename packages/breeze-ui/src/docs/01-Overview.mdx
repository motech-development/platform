# Breeze UI

Breeze UI is a React component library for Motech applications. It provides a consistent visual language with keyboard interaction, visible focus states and support for light and dark colour schemes.

Use component props to choose the treatment, size and state that suit an action. Each component page includes interactive examples, usage guidance and an API reference.

## Get started

Start with <a href="./?path=/docs/guides-02-installation--docs" target="_top">Installation</a> to add Breeze and its styles to your application. Then follow the <a href="./?path=/docs/guides-03-quick-start--docs" target="_top">Quick start</a> to connect a component to application state.

Wrap your components in <a href="./?path=/docs/foundation-breezeprovider--docs" target="_top">BreezeProvider</a> and supply your application's locale.

## Explore the components

Use <a href="./?path=/docs/actions-button--docs" target="_top">Button</a> to perform an action or submit a form. Choose from primary, secondary, quiet and danger treatments, with three sizes and a loading state that prevents repeat activation.

See <a href="./?path=/docs/guides-06-accessibility--docs" target="_top">Accessibility</a> for the supported interactions, verification coverage and guidance for accessible use.
