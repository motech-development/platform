# Breeze UI v4

Breeze provides a consistent, domain-neutral interface for Motech applications. It carries the Accounts design language: Public Sans, a quiet neutral palette, cyan primary actions and small control corners. Its appearance is closed, with no consumer theming or styling escape hatches.

This first v4 slice ships `BreezeProvider` and `Button`. Version 3's primitives, patterns and styling internals are removed. There are no compatibility exports. Existing applications pinned to published v2 remain outside this change.

Breeze owns accessible component interactions and visual consistency. Applications own domain compositions, data, business rules, copy and persistence. Additional primitives and neutral patterns follow in separate tickets; documentation describes only what currently ships.

The authoritative specification is [#1598](https://github.com/motech-development/platform/issues/1598), with this foundation delivered by [#1599](https://github.com/motech-development/platform/issues/1599). The v3 ADRs are historical; their v4 amendments are tracked in #1615.
