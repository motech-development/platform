# FormSection

`FormSection` groups related form fields under a title. Render it inside `BreezeProvider`.

## Title and description

`title` is required and labels the group. Add an optional `description` to explain the fields; it is announced with the group.

<Canvas of={Stories.Default} />

## Multiple sections

Use a separate section for each independent group of fields. Each description is announced only with its own group.

<Canvas of={Stories.MultipleSections} />

## Accessibility

`FormSection` renders a native `fieldset`, with `title` as its `legend`, so screen readers announce the title when focus enters the group.
