# PageHeader

`PageHeader` shows a page's main heading with an optional description and actions. Use one per page.

<Canvas of={Stories.Default} />

## Page actions

Pass buttons or links through `actions` to show them alongside the heading.

<Canvas of={Stories.WithActions} />

## Accessibility

The title is rendered as the page's level-one heading. Give each control in `actions` a clear accessible name.
