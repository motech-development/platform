# FormActions

`FormActions` lays out a form's buttons in a row with consistent spacing, wrapping them when space runs out. It only handles layout; submission and button behaviour stay with the buttons and form you provide.

## Basic actions

Actions align to the end of the row by default. Use `Stack` to space the fields and the action row; this example uses `Stack gap={4}`.

The example uses a secondary **Cancel** button and a **Save** button that submits the form.

<Canvas of={Stories.Default} />

## Start alignment

Set `align="start"` to place the actions at the start of the row.
