# StatStrip

`StatStrip` shows a few headline figures, such as a balance and the VAT owed, as labelled cells in one panel.

<Canvas of={Stories.Overview} />

## Figures

Pass your data as `items`, and use `getItem` to return a `StatStripItemDescriptor` for each one:

- `id`: a stable identifier;
- `label`: the visible name of the figure;
- `value` and `currency`: the amount and its ISO 4217 currency code;
- `badge` (optional): a badge after the label showing the figure's scope, such as the VAT scheme. It accepts `children`, `variant` and `aria-label`.

Amounts are formatted as currency for the provider locale, with a minus sign for negative amounts. A non-finite `value` or a malformed currency code, one that is not three letters, throws a `RangeError`. Codes are not checked against ISO 4217, so an unknown well-formed code is displayed as written. If you need to limit the currencies shown, validate the codes before passing them in.

## Other figures

Set `format` to show a figure that is not currency, without a `currency`:

- `date`: an ISO calendar date, formatted as a long date for the provider locale;
- `number`: a number formatted for the provider locale, such as a count of days;
- `text`: short text, such as a VAT scheme name.

These figures use a smaller size than currency amounts. You can mix them with currency figures in one strip.

## Loading

Set `loading` to show three placeholder cells shaped like labels and figures. `items` and `getItem` are optional while loading.

<Canvas of={Stories.Loading} />

## Phone layout

Below 901px, the cells stack in a single column with a divider between them.

<Canvas of={Stories.Phone} />

## Accessibility

The panel is a group named by the required `aria-label`. Its figures form a description list, so screen readers announce each label with its figure.
