# StatStrip

`StatStrip` shows a few headline currency figures, such as a balance and the VAT owed, as labelled cells in one panel.

<Canvas of={Stories.Overview} />

## Figures

Pass your data as `items`, and use `getItem` to return a `StatStripItemDescriptor` for each one:

- `id`: a stable identifier;
- `label`: the visible name of the figure;
- `value` and `currency`: the amount and its ISO 4217 currency code;
- `badge` (optional): a badge after the label showing the figure's scope, such as the VAT scheme. It accepts `children`, `variant` and `aria-label`.

Amounts are formatted as currency for the provider locale, with a minus sign for negative amounts. A non-finite `value` or an invalid currency code throws a `RangeError`.

## Loading

Set `loading` to show three placeholder cells shaped like labels and figures. `items` and `getItem` are optional while loading.

<Canvas of={Stories.Loading} />

## Phone layout

Below 901px, the cells stack in a single column with a divider between them.

<Canvas of={Stories.Phone} />

## Accessibility

The panel is a group named by the required `aria-label`. Its figures form a description list, so screen readers announce each label with its amount.
