# StatePanel

`StatePanel` explains why there is no content to show, either because there is nothing yet or because loading it failed. Pass a `title`, a `description` and a `variant` of `empty` or `error`, with an optional action.

## Empty states

Use `variant="empty"` when there is no content yet. Add an `action`, such as creating the first item, when there is an obvious next step.

<Canvas of={Stories.Empty} />

<Canvas of={Stories.EmptyWithAction} />

If the panel shows the page's primary action, leave that action out of the page header so it does not appear twice.

## Error states

Use `variant="error"` when content could not be loaded. To let people retry, pass an `action` whose `onAction` performs the recovery.

<Canvas of={Stories.Error} />

<Canvas of={Stories.ErrorWithRecovery} />

## Icon

Empty states show a document icon in the brand colour, and error states a warning icon in the danger colour. Set `icon` to another Breeze icon when it better describes the content.

<Canvas of={Stories.CustomIcon} />

## Accessibility

The panel is a section labelled by its title. It is not a live region, so when it replaces content dynamically, announce the change yourself if people need to hear it.
