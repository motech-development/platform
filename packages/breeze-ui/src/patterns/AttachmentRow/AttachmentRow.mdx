# AttachmentRow

`AttachmentRow` presents one attached file in a compact row. The caller provides
the file name, whether it is a document or photograph, its size in bytes, and a
visible status such as `Uploaded` or `Upload failed`. Size formatting follows
the required Breeze provider locale.

## Document and photo thumbnails

Documents use a page preview and photographs use the supplied image thumbnail
or a camera placeholder. The file type is also written as visible text, so the
thumbnail is not the only way to tell them apart. Only a photograph accepts a
`thumbnailUrl`.

## Open and menu actions

Pass `onOpen` to show a direct Open button. Pass action descriptors and an
`onAction` callback together to show the overflow menu; `onAction` receives the
selected action from `actions`. Each action has a visible label; icons only
decorate those labels. The Open button keeps its short visible label, and the
overflow menu opens from an icon-only More actions button. Both include the
file name in their accessible names.

The menu opens aligned to the end edge of its button. Give a destructive action, such as
Remove, `tone: 'danger'` and its own `section` so it shows in the danger
colour below a divider.

## Narrow containers

When there is not enough horizontal room, the row wraps its actions below the
file details so the file information remains readable.

<Canvas of={Stories.NarrowContainer} />

## Visible state and loading

The `status` text stays visible and updates are announced politely regardless
of the file type or thumbnail. While the file details are unavailable, set
`loading` to show the row-shaped loading placeholder and labelled progress bar.
