# AttachmentRow

`AttachmentRow` shows one attached file in a compact row, with its name, type, size, status and actions. Use it to list the files attached to a record.

Pass `filename`, `fileType` (`document` or `photo`), `sizeBytes` and a visible `status` such as `Uploaded` or `Upload failed`. The size is formatted for the `BreezeProvider` locale.

## Documents and photos

Documents show a page preview. Photos show the image passed as `thumbnailUrl`, or a camera placeholder without one; only photos accept `thumbnailUrl`. The file type is also written as text, so the thumbnail is not the only way to tell them apart.

## Actions

Pass `onOpen` to show an **Open** button. To open the file in a `DocumentViewer` with a transition between the two, give both the same `transitionName`.

To add an overflow menu, pass an `actions` array together with `onAction`. Each action has an `id` and a visible `label`, plus an optional `icon`, `description` and `disabled` flag. `onAction` receives the selected action. The menu opens from a **More actions** button, aligned to its end edge.

For a destructive action such as Remove, set `tone: 'danger'` and give it its own `section` so it appears in the danger colour below a divider.

## Narrow containers

When horizontal space is limited, the actions wrap below the file details so the file information stays readable.

## Status and loading

The `status` text is always visible. Set `loading` while the file details are unavailable to show a row-shaped placeholder with a labelled progress bar.

## Accessibility

- The **Open** and **More actions** buttons include the file name in their accessible names.
- Changes to `status` are announced politely to screen readers.
- Action icons are decorative; each action is named by its label.
