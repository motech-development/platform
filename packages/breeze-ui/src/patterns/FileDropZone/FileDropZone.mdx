# FileDropZone

`FileDropZone` lets people add files by dragging them onto the drop area or by using the **Choose files** button. `label` is shown above the drop area and names it.

<Canvas of={Stories.Default} />

## Compact

Set `compact` to show the drop area as a single row, the same height as an `AttachmentRow`. A single attachment then keeps its position whether or not a file is attached. The secondary text stays on one line and is truncated with an ellipsis.

<Canvas of={Stories.Compact} />

## Take photo

Set `camera` to add a **Take photo** button before **Choose files**. On phones it requests the rear camera, although the browser or device may use its own default; on other devices it opens an image picker.

Cameras produce JPEG photos, so **Take photo** appears only when `accept` is omitted or allows JPEG through `image/*`, `image/jpeg`, `.jpg`, `.jpeg` or `*/*`. Photos go through the same type, size and count checks as chosen files and are passed to `onFilesAdded` in the same way.

On touch devices and narrow screens (below 901px), **Take photo** is filled in the brand colour. On narrow screens:

- in the default layout, **Take photo** fills the action row and the drag-and-drop instruction is hidden;
- in `compact` mode, both buttons show only their icons and keep their accessible names.

## File limits

- `accept` takes a comma-separated list of file extensions and MIME types, such as `.pdf,image/*`. Dropped files are checked against the same list. `.jpg` and `.jpeg` each accept either extension, and an untyped file named `.jpg` or `.jpeg` is treated as `image/jpeg`.
- `maxSize` sets the largest file size, in bytes.
- `maxFiles` sets the total number of attachments allowed. When files are already attached, pass their number as `currentFileCount`.

Accepted files are passed to `onFilesAdded` as a read-only array. Uploading and storing them is up to your application. Rejected files show their reason as visible text.

## Localisation

The button text, instructions and feedback can be translated through the `messages` prop of `BreezeProvider`. Keep the placeholders listed in the BreezeProvider locale section. Each message is announced in its own language.

## Accessibility

- **Choose files** opens the native file picker, so keyboard users can add files without dragging.
- Each rejection reason is also announced through a polite live region.
