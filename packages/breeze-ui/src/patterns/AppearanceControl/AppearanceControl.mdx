# AppearanceControl

`AppearanceControl` lets people choose a Light, Auto or Dark colour scheme for your application. Place it anywhere inside `BreezeProvider`; it reads and updates the provider's appearance, and Auto follows the operating system preference.

<Canvas of={Stories.Default} />

## Remembering the choice

The control does not save the choice in browser storage. To restore it on the next visit, store the value reported by the provider's `onAppearanceChange` and pass it back as `appearance`.

## Shadows

Shadows change with the selected appearance, along with colours and native controls.

<Canvas of={Stories.ThemeReactiveShadow} />

## Accessibility

The three options form a single-selection group named by the provider's `appearance` message, so screen readers announce which option is selected.
