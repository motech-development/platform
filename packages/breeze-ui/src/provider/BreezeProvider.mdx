# BreezeProvider

`BreezeProvider` provides the locale and styles that Breeze UI components require. Render it once, above every Breeze UI component. Components rendered without a provider throw an error.

```tsx
<BreezeProvider locale="en-GB">
  <Button>Save changes</Button>
</BreezeProvider>
```

<Canvas of={Stories.Default} />

## Locale

`locale` takes a BCP 47 language tag. It sets the `lang` attribute and the text direction of the provider's root element.

Only English (`en-GB`) messages are bundled. Supply `messages` to translate Breeze's loading announcement into the provider locale. Without an override, the announcement uses the English message and is marked `lang="en-GB"`, independently of the surrounding content's language.

```tsx
<BreezeProvider locale="fr-FR" messages={{ loading: 'Chargement' }}>
  <Button loading>Enregistrer</Button>
</BreezeProvider>
```

<Canvas of={Stories.Locale} />

## Colour scheme

Components follow the operating system colour scheme. To set the scheme from your application, add `data-theme="light"` or `data-theme="dark"` to the `html` element.
