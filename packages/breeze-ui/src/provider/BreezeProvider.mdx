# BreezeProvider

Place `BreezeProvider` around Breeze content and supply a BCP 47 `locale`. Components throw a clear error outside the provider. Its root carries `data-breeze-root`, `lang` and the direction inferred by React Aria's locale provider.

```tsx
<BreezeProvider locale="en-GB">
  <Button>Save changes</Button>
</BreezeProvider>
```

<Canvas of={Stories.Default} />

This foundation exposes only `children` and `locale`. Appearance controls, routing, messages, portal hosts, time zones and toast limits arrive with their owning v4 tickets. There is no `direction` override, and no styling or slot passthrough. Direction inference is not a claim of RTL test coverage.

The provider does not change document attributes or persist preferences. CSS alone follows the OS colour scheme unless the application sets `data-theme="light"` or `data-theme="dark"` on the document element. Tokens and `color-scheme` live there; painting is scoped to Breeze roots.
