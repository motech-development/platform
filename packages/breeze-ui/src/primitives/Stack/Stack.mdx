# Stack

`Stack` arranges related content vertically. Choose `gap` from the 4px Breeze spacing scale and use `horizontalAlign` to align the children across the row axis.

<Canvas of={Stories.Default} />

## Alignment

The default stretches children. Use `start`, `center` or `end` when their intrinsic width should be retained.

<Canvas of={Stories.Centred} />

## Accessibility

The default `div` adds no semantics. Select `main`, `nav` or `section` only when the content has that meaning, and label landmarks or regions with `aria-label`.

Loading belongs to the items inside the stack. Compose loading-capable children or explicit `Skeleton` elements so placeholders match the final vertical rhythm.
