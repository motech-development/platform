# IconButton

An icon button performs an action using an icon alone, such as closing a panel or opening more actions. Use it when the icon is clear enough without visible text.

## Basic icon button

Set `name` to choose an icon from the Breeze icon set, and `label` to name the action for screen readers. `label` is required because the button has no visible text.

<Canvas of={Stories.Default} />

## Variants and sizes

`variant` accepts the same values as `Button`: `secondary` (default), `primary`, `quiet` and `danger`. `secondary` suits most icon-only actions, such as Close and More actions, which sit beside content rather than leading it.

`size` accepts `sm`, `md` (default) and `lg`. The button is a 32, 36 or 52px square, with a 16, 20 or 24px icon.

<Canvas of={Stories.TreatmentsAndSizes} />

## Shapes

`shape` accepts `square` (default), with rounded corners, and `circle`, for a standalone action such as the centre action in `ApplicationShell`.

<Canvas of={Stories.Shapes} />

## Loading

Set `loading` while the action is in progress. The icon is replaced by a placeholder, and the button cannot be activated again until loading ends.

<Canvas of={Stories.Loading} />

## Disabled

Set `disabled` to prevent activation. A disabled button is also removed from the tab order.

<Canvas of={Stories.Disabled} />

## Handling actions

Pass `onAction` to respond when the button is activated by click, tap or keyboard. It is called with no arguments.

<Canvas of={Stories.Activation} />

## Accessibility

Screen readers announce the `label` as the button's name, including while it is loading; the icon itself is hidden. On touch devices the button has a target of at least 44px.

The button also accepts `aria-describedby`, `aria-controls`, `aria-expanded` and `aria-haspopup` when it opens or controls other content.
