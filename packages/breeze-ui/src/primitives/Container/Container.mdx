# Container

`Container` centres page or reading content and limits its width. By default it uses the `page` width and adds inline padding of 16px below 901px and 28px from 901px; set `padded={false}` to remove it.

<Canvas of={Stories.Page} />

## Reading widths

Set `width="read"` for longer explanatory text, or `width="prose"` for short supporting copy.

<Canvas of={Stories.Reading} />

## Loading

Containers have no loading state of their own. Use loading-capable children or `Skeleton` elements inside the container so the placeholders match the final page layout.

## Accessibility

- Use `element="main"` only once per page.
- When a page has several `nav` or `section` containers, give each one an `aria-label` so they can be told apart.
