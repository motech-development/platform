# Container

`Container` caps and centres page or reading content. The page width includes 16px inline padding below `md` and 28px at and above it.

<Canvas of={Stories.Page} />

## Reading widths

Use `read` for longer explanatory text and `prose` for compact supporting copy.

<Canvas of={Stories.Reading} />

## Accessibility

Use `element="main"` only once per page. Label multiple navigation or region containers so they can be distinguished.

Loading belongs to the content inside the container. Compose loading-capable children or explicit `Skeleton` elements so placeholders match the final page structure.
