# Dialog

`Dialog` opens a centred modal window for a focused task that takes priority over the rest of the page. Render it inside `BreezeProvider`.

## Basic dialog

`trigger` sets the label of the button that opens the dialog. `title` sets the dialog's visible heading and accessible name, and `children` its content. The dialog also includes a close button.

```tsx
<Dialog title="Delivery details" trigger="View delivery details">
  <Typography>Your delivery details appear here.</Typography>
</Dialog>
```

## Controlled

By default, the dialog manages its own open state. Set `defaultOpen` to start it open, and use `onOpenChange` to respond to changes.

To control the dialog from your application state, pass both `open` and `onOpenChange`. `open` and `defaultOpen` cannot be combined.

```tsx
<Dialog
  onOpenChange={setOpen}
  open={open}
  title="Delivery details"
  trigger="View delivery details"
>
  <Typography>Your delivery details appear here.</Typography>
</Dialog>
```

## Dismissal

By default, pressing Escape or clicking outside the dialog closes it. Set `dismissible={false}` to keep it open in those cases; the close button still works.

## Accessibility

- Focus moves into the dialog when it opens, stays inside it while open, and is restored when it closes.
- The close button's accessible name comes from the provider's messages.
- The dialog keeps the provider's locale and text direction.
- Opening and closing animations respect the reduced-motion preference.
