# IconTile

`IconTile` decorates state panels, rows and other content with a fixed-size icon wash.

<Canvas of={Stories.Treatments} />

## Direction markers

Use the compact circular form for direction markers: `positive` for money in and `strong` for money out. `strong` shares the `neutral` wash with full-strength ink.

<Canvas of={Stories.Direction} />

## Accessibility

Artwork is decorative by default. Supply `label` only when no adjacent text names its meaning; never rely on the tile colour alone.
