# ComboBox

`ComboBox` is a text field with a list of suggestions that filters as people type. Use it when there are too many options to scan in a select, or when people may enter their own value.

<Canvas of={Stories.Default} />

## Items

Pass your data as `items`, and use `getItem` to return an `ItemDescriptor` for each one. It has an `id` and a `label`, plus an optional `description`, `icon`, `badge` and `disabled` flag. Items are rendered from these fields only.

<Canvas of={Stories.Description} />

## Filtering and free text

Typing filters the suggestions by their labels. Set `allowsCustomValue` to also accept text that does not match a suggestion; `onChange` then receives the selected item, the entered text or `null`.

When nothing matches, or `items` is empty, the list stays open with a message that repeats the entered text. With `allowsCustomValue`, the list closes instead, because the entered text is already a valid value.

<Canvas of={Stories.NoMatches} />

<Canvas of={Stories.FreeText} />

## Validation

Set `error` to a non-empty message to show it and mark the field invalid. Set `required` to mark the field as required.

<Canvas of={Stories.Error} />

## Read only and disabled

Set `readOnly` to show a value that cannot be changed, or `disabled` to prevent interaction.

<Canvas of={Stories.ReadOnly} />

## Loading

Set `loading` while the value is unavailable. The field keeps its shape and cannot be used until loading ends.

<Canvas of={Stories.Loading} />

## Controlled values

Pass `value` and `onChange` to control the field. `onChange` receives the selected item, custom text or `null`.

For an uncontrolled field, use `defaultValue` with an optional `onChange`. Controlled and uncontrolled props cannot be combined.

<Canvas of={Stories.Controlled} />

## Accessibility

- The visible label names the input, and its description and error are announced with it.
- Use the arrow keys to move through the suggestions, Enter to choose one and Escape to close the list.
