# Inline

`Inline` arranges related items in a row, such as a group of buttons or badges. Set `gap` to choose the spacing from the Breeze spacing scale, `verticalAlign` to align items (centred by default) and `justify` to distribute them along the row.

<Canvas of={Stories.Default} />

## Wrapping

Set `wrap` when the items may not fit on one line, such as a list of labels or actions. Items that do not fit move onto the next row.

<Canvas of={Stories.Wrapped} />

## Loading

`Inline` has no loading state of its own. Show loading inside each item, using components with a `loading` prop or a `Skeleton` sized like the final content.

## Accessibility

`Inline` renders a `div` by default, which adds no meaning for assistive technology. Use `element` to choose a landmark or region only when the content is one, and name it with `aria-label`. Items are read in the same order they appear.
