# Inline

`Inline` lays related items out horizontally. Its gap, alignment and distribution choices are closed to the arrangements used by Breeze.

<Canvas of={Stories.Default} />

## Wrapping

Enable `wrap` for collections of labels or actions that may not fit on one line.

<Canvas of={Stories.Wrapped} />

## Accessibility

Choose a semantic element only when the content forms a landmark or labelled region. Visual order and document order remain the same.

Loading belongs to the items inside the row. Compose loading-capable children or explicit `Skeleton` elements so placeholders retain the intended item sizes.
