# NumberField

`NumberField` is a labelled input for entering numbers, such as an amount.
It reads and displays numbers using the provider's locale, and shows figures
with tabular numerals so digits line up.

There are no stepper buttons. Up and Down arrow keys change the value by
`step`, which defaults to `1`. Beyond the locale's number conventions, values
are not formatted unless you pass `formatOptions`.

<Canvas of={Stories.Default} />

## Sizes

`size` defaults to `md`, a 38px control with 13px figures. Use `lg` for a
form's main amount: a 52px control with 20px semibold figures. Fields in the
same row should use the same size.

<Canvas of={Stories.Large} />

## Description and errors

Use `description` for guidance about what to enter. Pass a non-empty `error`
to mark the field invalid and show the message; there is no separate `invalid`
prop.

## States

`required`, `disabled` and `readOnly` behave as they do on a native input.

Set `loading` while the value is not yet available. The field keeps its shape,
screen readers announce the provider's loading message, and the value cannot be
typed or stepped until loading ends.

## Controlled

To control the value, pass both `value` and `onChange`. `onChange` receives the
new number, not a DOM event. While the input is empty, the value is `NaN`, so
you can tell an empty field from zero.

For an uncontrolled field, pass `defaultValue` and optionally `onChange`.
Controlled and uncontrolled props cannot be combined.

<Canvas of={Stories.Controlled} />

## Accessibility

The visible label names the input, and screen readers announce the description
and any error with it. Use `ref` to reach the native input, for example to
focus it.
