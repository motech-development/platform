# NumberField

`NumberField` is a flat labelled numeric input backed by React Aria. It uses
the Breeze locale and displays figures with tabular numerals. There are no
stepper buttons: the Up and Down arrow keys change the value by `step`. Values
remain unformatted except for React Aria's locale-aware input behaviour.

<Canvas of={Stories.Default} />

## Sizes

`size` defaults to `md`, the standard 38px control with 13px figures. Use `lg`
for a form's primary amount: a 52px control with 20px semibold figures. Fields
that share a row should share a size.

## Supporting text and errors

Use `description` for guidance. A non-empty `error` marks the field invalid and
associates the message with the native input. There is no separate invalid prop.

## States

`required`, `disabled` and `readOnly` map to the corresponding accessible input
semantics. `loading` keeps the field's shape, announces the provider loading
message and prevents typing or stepping until it is removed.

## Controlled values

Provide both `value` and `onChange` for controlled usage. The callback receives
the next number, never a DOM event. React Aria reports `NaN` while the input is
empty, which lets applications distinguish an empty value from zero. Use
`defaultValue` and an optional `onChange` for uncontrolled usage; the two forms
cannot be mixed.

<Canvas of={Stories.Controlled} />

## Accessibility

The visible label names the native input. Descriptions and errors are announced
through React Aria's field relationships, and the field exposes its native
input through `ref`.
