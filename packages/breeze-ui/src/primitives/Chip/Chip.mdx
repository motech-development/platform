# Chip

`Chip` is a compact pill-shaped filter. It stays independently selectable when
shown beside other chips, and exposes its state as `aria-pressed`.

<Canvas of={Stories.Default} />

## Pressed state

Use `defaultPressed` for an uncontrolled chip, or `pressed` and `onChange` when
the application owns the state. The callback receives the next pressed value.
Choose one of these state approaches for each chip.

<Canvas of={Stories.Pressed} />

<Canvas of={Stories.FilterRow} />

## Loading

Set `loading` while saving a choice. A skeleton replaces the visible label while
the chip keeps its name and width. Activation resumes when loading clears.

<Canvas of={Stories.Loading} />

## Disabled and touch targets

Set `disabled` to prevent activation. Chips have a 34px minimum height and
expand to a 44px minimum touch target.

<Canvas of={Stories.Disabled} />

## Accessibility

The visible label names the button. `aria-label`, `aria-labelledby` and
`aria-describedby` support alternate and supplemental names. The button exposes
its pressed state and supports keyboard activation.
