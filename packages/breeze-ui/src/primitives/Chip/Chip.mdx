# Chip

`Chip` is a compact, pill-shaped toggle for filtering content. Each chip is turned on and off independently, even in a row with other chips.

<Canvas of={Stories.Default} />

## Pressed state

Use `defaultPressed` for an uncontrolled chip, or `pressed` and `onChange` to control it. `onChange` receives the new pressed value. Use only one of these approaches for each chip.

<Canvas of={Stories.Pressed} />

<Canvas of={Stories.FilterRow} />

## Loading

Set `loading` while a choice is being saved. A placeholder replaces the visible label, and the chip keeps its name and width. It can be activated again once loading ends.

<Canvas of={Stories.Loading} />

## Disabled

Set `disabled` to prevent activation.

<Canvas of={Stories.Disabled} />

## Accessibility

- The chip is a button named by its visible label. Use `aria-label`, `aria-labelledby` or `aria-describedby` to provide an alternative or additional description.
- Its state is announced as pressed or not pressed, and it can be toggled with the keyboard.
- Chips are at least 34px tall and have a minimum 44px touch target.
