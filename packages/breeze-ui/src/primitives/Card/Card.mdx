# Card

`Card` groups related non-interactive content on a surface with panel elevation. Padding is selected from the Breeze spacing scale.

<Canvas of={Stories.Surface} />

## Raised cards

Use `raised` for a group nested inside another surface, not to create stronger elevation.

<Canvas of={Stories.Raised} />

## Accessibility

Cards do not become interactive. Use `article`, `aside` or `section` only when that semantic grouping is meaningful, and provide a label where the element creates a region.

Loading belongs to the content inside the card. Compose loading-capable children or explicit `Skeleton` elements so placeholders match the final content structure.
