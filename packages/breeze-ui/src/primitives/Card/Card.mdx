# Card

`Card` groups related content on a bordered panel. Set `padding` to a value from the Breeze spacing scale; it defaults to `4`.

<Canvas of={Stories.Surface} />

## Raised cards

Use `variant="raised"` for a group nested inside another surface. It does not add stronger elevation.

<Canvas of={Stories.Raised} />

## Titles

Set `title` to add a header with a second-level heading. Add `count` to show a neutral count beside the title.

<Canvas of={Stories.TitledWithCount} />

Use `action` for one control at the end of the header, such as a link to the full list. With a title, `padding` applies only to the content below it, so set `padding={0}` for rows that run edge to edge.

<Canvas of={Stories.TitledWithAction} />

## Loading

Cards have no loading state of their own. Use loading-capable children or `Skeleton` elements inside the card so the placeholders match the final content.

## Accessibility

- The card itself is not interactive and cannot be made clickable as a whole.
- Set `element` to `article`, `aside` or `section` only when that grouping is meaningful, and give a region a name with `title` or `aria-label`.
- A titled card is named by its heading, so `aria-label` is not accepted alongside `title`.
