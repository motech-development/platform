# Icon

`Icon` displays an icon from the Breeze icon set. Set `name` to choose the icon; names describe what the icon means, such as `incoming` or `document`, rather than what it looks like.

<Canvas of={Stories.Gallery} />

## Sizes

Set `size` to choose one of the following square sizes. It defaults to `sm`.

| Size  | Pixels | Typical use                                                 |
| ----- | ------ | ----------------------------------------------------------- |
| `2xs` | 14     | Overlay close and menu trigger chevrons                     |
| `xs`  | 15     | Field chevrons, selected ticks, row tiles and small buttons |
| `sm`  | 16     | Buttons, menu items, calendar navigation and toasts         |
| `md`  | 17     | Date picker trigger and compact upload thumbnail            |
| `lg`  | 20     | Medium icon buttons                                         |
| `xl`  | 21     | Bottom navigation                                           |
| `2xl` | 22     | Large icon tiles in content states                          |
| `3xl` | 24     | Large icon buttons, such as the raised action               |
| `4xl` | 26     | Stacked file drop zone                                      |

## Accessible names

Icons are decorative by default and hidden from assistive technology. Pass `label` only when the icon carries meaning that no nearby text provides; screen readers then announce the label.
