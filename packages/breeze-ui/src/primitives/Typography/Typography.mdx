# Typography

`Typography` displays text in one of the Breeze text styles, called roles: `money`, `amount`, `heading`, `title`, `body`, `caption`, `label` and `micro`. It also formats currency amounts and dates for the provider's locale.

<Canvas of={Stories.Roles} />

## Numeric figures

The `money` role is designed for figures: digits line up in columns and are spaced slightly tighter. Set `numeric` to give figures in any other role the same treatment; they are also aligned to the end of the line. Text without `numeric` keeps its normal spacing.

## Money and dates

Set `format="currency"` or `format="date"` and pass the raw value; it is formatted for the nearest `BreezeProvider` locale.

- Currency uses the `money` role for headline figures, or the `amount` role, a semibold body-size figure, for amounts in rows. The sign follows the locale's placement and uses a true minus character.
- Dates take an ISO calendar date string, typed as `IsoCalendarDate`, such as `2026-03-14`.

<Canvas of={Stories.Formatting} />

### Signs

`sign` controls the sign of a currency amount:

- `auto` (default) shows a sign on negative amounts only.
- `always` also shows `+` on positive amounts.
- `never` hides the sign, for content that shows direction another way.

Zero is never signed, including negative zero and amounts that round to zero, so `-0.004` displays as `£0.00`.

### Dates and time zones

Calendar dates always display the day you pass, whatever the user's time zone. The provider's `timeZone` is not applied to them.

### Invalid values

An invalid currency value throws a `RangeError` naming the problem, rather than displaying a misleading figure:

- `currency` must be a well-formed three-letter code, such as `GBP`. Codes are
  not checked against ISO 4217, so an unknown well-formed code is displayed as
  written.
- `value` must be a finite number. `NaN` and `Infinity` are rejected.
- An invalid `locale` is rejected by `BreezeProvider` before any value is formatted, so it is never reported as a currency error.

Validate or convert untrusted amounts before rendering them. A date that does not exist, such as `2026-02-30`, is displayed as written.

## Loading

Set `loading` while the value is not yet available. A placeholder keeps the text's place.

<Canvas of={Stories.Loading} />

## Accessibility

Each role renders a default element: `heading` renders an `h2`, `title` an `h3`, `body` a `p` and the other roles a `span`. Set `element` to match your page structure, for example `element="h1"` for the page heading. Do not use colour alone to show direction or status.
