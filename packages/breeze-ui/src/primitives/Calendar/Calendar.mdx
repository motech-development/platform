# Calendar

`Calendar` shows a month grid for picking a single date. To pick a date from a form field, use `DatePicker`.

<Canvas of={Stories.Default} />

The header shows the month with previous and next month buttons. Weeks start on Monday, and each month shows six rows, with dates from the neighbouring months in muted text. Weekday names use the provider locale. The selected date has a brand fill, and today has a brand outline unless it is selected.

## Disabled

Set `disabled` to prevent the date from being changed.

<Canvas of={Stories.Disabled} />

## Controlled values

Pass `value` and `onChange` to control the selected date. `onChange` receives an ISO `YYYY-MM-DD` string.

For an uncontrolled calendar, use `defaultValue` with an optional `onChange`. Controlled and uncontrolled props cannot be combined.

## Accessibility

- `label` names the calendar.
- Use the arrow keys to move between dates and Enter or Space to select one.
- Each date is announced with its full weekday and date name in the provider locale.
- The selected date's fill has at least 3:1 contrast with the background in both light and dark appearances.
