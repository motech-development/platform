# Checkbox

`Checkbox` is a closed, labelled boolean control. Its label, optional
description and optional error are flat props, so applications do not need to
compose checkbox parts or provide an escape hatch.

<Canvas of={Stories.Default} />

## Supporting text and errors

Use `description` for guidance. It sits under the label, beside the box. A
non-empty `error` marks the checkbox invalid, appears in the same place and is
associated with the native input. There is no separate invalid prop.

<Canvas of={Stories.Error} />

## States

`required`, `disabled` and `readOnly` map to the corresponding accessible input
semantics. A disabled checkbox greys its box and keeps its label legible.
`loading` keeps the checkbox's shape, announces the provider loading message and
prevents selection until it is removed.

## Controlled values

Provide both `selected` and `onChange` for controlled usage. The callback
receives the next boolean, never a DOM event. Use `defaultSelected` and an
optional `onChange` for uncontrolled usage; the two forms cannot be mixed.

<Canvas of={Stories.Controlled} />

## Accessibility

The visible label alone names the native checkbox, even though its supporting
text shares the clickable label. Descriptions and errors are announced through
React Aria's field relationships, and the field exposes its native input through
`ref`.
