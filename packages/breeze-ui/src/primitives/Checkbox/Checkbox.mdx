# Checkbox

`Checkbox` lets people turn a single option on or off. Pass the visible text as `label`.

<Canvas of={Stories.Default} />

## Description and errors

Use `description` for guidance shown under the label. Set `error` to a non-empty message to show it in the same place and mark the checkbox invalid.

<Canvas of={Stories.Description} />

<Canvas of={Stories.Error} />

## Required

Set `required` to mark the checkbox as required.

<Canvas of={Stories.Required} />

## Disabled

Set `disabled` to prevent selection and focus. The box is greyed out and the label stays legible.

<Canvas of={Stories.Disabled} />

## Read only

Set `readOnly` to prevent changes while keeping the checkbox focusable and included in form submission.

<Canvas of={Stories.ReadOnly} />

## Loading

Set `loading` while the value is unavailable. The checkbox keeps its shape, announces the provider's loading message and cannot be selected until loading ends.

<Canvas of={Stories.Loading} />

## Controlled values

Pass `selected` and `onChange` to control the checkbox. `onChange` receives the new `boolean` value.

For an uncontrolled checkbox, use `defaultSelected` with an optional `onChange`. Controlled and uncontrolled props cannot be combined.

<Canvas of={Stories.Controlled} />

## Accessibility

- The checkbox is a native input named by its `label`. Clicking the description also toggles it, but the description is not part of the name.
- The description and error are announced with the checkbox.
- `ref` gives access to the native input.
