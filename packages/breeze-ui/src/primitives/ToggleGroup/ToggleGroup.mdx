# ToggleGroup

`ToggleGroup` presents a single choice as connected segments. Each option is a
button with an accessible pressed state. Press the selected option again to
clear the selection.

<Canvas of={Stories.Default} />

## Options

Provide `items` and a `getItem` function that describes each option. Return a
unique `id` and visible `label`. You can also provide a `description`, `icon`,
`badge` or `disabled` flag. Disabled options cannot be selected.

<Canvas of={Stories.DisabledOption} />

## Controlled selection

Use `defaultSelected` with an optional `onChange` for uncontrolled use. Provide
`selected` and `onChange` when the application owns state. The callback receives
the selected item, or `null` when the choice is cleared. Choose one of these
state approaches for each group.

<Canvas of={Stories.Controlled} />

## Loading

Set `loading` while saving a selection. A slim loading bar replaces each
option's content while its size and selected appearance stay in place. Changes
resume when loading clears.

<Canvas of={Stories.Loading} />

## Full width

Set `fullWidth` to stretch the group across its container and share the width
equally between options, for example when the choice sits in a form.

<Canvas of={Stories.FullWidth} />

## Sizes and accessibility

`size` accepts `sm` (default), `md` or `lg`, giving the group a minimum height
of 34, 38 or 52px to align with other controls of the same size. On coarse
pointers the `sm` and `md` groups grow to 48px. Give each group an `aria-label`;
each option exposes whether it is pressed and supports keyboard interaction.
