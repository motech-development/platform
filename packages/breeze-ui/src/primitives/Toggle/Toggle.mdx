# Toggle

`Toggle` represents an on/off choice as a button. Its pressed state is exposed
with `aria-pressed`; use a `Checkbox` when the choice belongs in a form.

<Canvas of={Stories.Default} />

## Pressed state

Use `defaultPressed` for an uncontrolled toggle, or `pressed` and `onChange` when
the application owns the state. The callback receives the next boolean value,
not a DOM event. These state props are mutually exclusive.

## Sizes and disabled state

`size` accepts `sm`, `md` (default) or `lg`, with minimum heights of 34, 38 and
52px. Coarse pointers receive a 44px minimum target. Disabled toggles cannot be
activated.

<Canvas of={Stories.Disabled} />

## Accessibility

The visible label names the button. `aria-label`, `aria-labelledby` and
`aria-describedby` support alternate and supplemental names. React Aria provides
the pressed state and keyboard activation.
