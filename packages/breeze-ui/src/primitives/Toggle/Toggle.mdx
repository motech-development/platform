# Toggle

`Toggle` is a button that switches something on or off, such as a filter.
Use a `Checkbox` instead when the choice belongs in a form.

<Canvas of={Stories.Default} />

## Pressed state

For an uncontrolled toggle, set `defaultPressed` to choose its starting state.
To control it from your own state, pass both `pressed` and `onChange`.
`onChange` receives the new pressed value. Controlled and uncontrolled props
cannot be combined.

<Canvas of={Stories.Pressed} />

<Canvas of={Stories.Controlled} />

## Loading

Set `loading` while saving a choice. A placeholder replaces the visible label,
and the button keeps its name and width. It cannot be pressed until loading
ends.

<Canvas of={Stories.Loading} />

## Sizes

`size` accepts `sm`, `md` (default) or `lg`, with minimum heights of 34, 38 and
52px. On touch devices, every size has a target of at least 44px.

<Canvas of={Stories.Sizes} />

## Disabled

Set `disabled` to prevent the toggle from being pressed.

<Canvas of={Stories.Disabled} />

## Accessibility

The visible label names the button, and screen readers announce whether it is
pressed. Use `aria-label` or `aria-labelledby` to give it a different name, and
`aria-describedby` to add a description. Press Space or Enter to switch it.
