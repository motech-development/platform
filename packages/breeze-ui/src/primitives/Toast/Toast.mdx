# Toast

A toast is a short confirmation that an action has completed, such as “Changes saved”. Screen readers announce it, and it never moves focus.

In most cases, show toasts with the `useToast` hook, which displays each message for 2.6 seconds. A `Toast` you render yourself stays on screen until you remove it.

<Canvas of={Stories.Default} />

## Showing a toast

Call `useToast` in a component below `BreezeProvider`. It returns a function that shows a message; pass text already translated into the user's language.

```tsx
import { Button, useToast } from '@motech-development/breeze-ui';

function SaveAction() {
  const enqueue = useToast();

  return (
    <Button onAction={() => enqueue('Changes saved')}>Save changes</Button>
  );
}
```

Up to three toasts are shown at once. Further messages wait and appear in the order they were sent, as earlier ones expire. Set `toastLimit` on `BreezeProvider` to change how many are shown at once.

## Layout

A toast is 288px wide on both desktop and mobile, and appears below the top bar, aligned with the page content. Toasts shown with `useToast` have no action, dismiss or undo button.

<Canvas of={Stories.Mobile} />

## Accessibility

Screen readers announce each toast as a status message without interrupting the user. A toast cannot be focused or dismissed: Tab and Shift+Tab skip it, Escape does not close it, and focus stays where it was.
