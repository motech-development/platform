# SkipLink

`SkipLink` is visually hidden until it receives keyboard focus. It uses the nearest `BreezeProvider` message for its accessible name and language.

<Canvas of={Stories.KeyboardNavigation} />

## Choose a focusable target

Set `targetId` to the `id` of the page's main content landmark. Give that target `tabIndex={-1}` so it can receive programmatic focus without adding it to the ordinary Tab order. The target ID must be unique in the document.

`ApplicationShell` renders this link first and generates a unique, focusable main target for its children.
