# Skeleton

`Skeleton` is a placeholder shown in place of content while it loads. Set `shape` to `text` (default), `rectangle` or `circle`, and `inlineSize` (width) and `blockSize` (height) to match the content it replaces. Both accept any CSS length, such as `120` or `'60%'`.

<Canvas of={Stories.Shapes} />

## Backgrounds

Place skeletons on the page background or a standard surface. Avoid raised surfaces: in dark mode, a skeleton has the same colour as a raised surface and is not visible on it.

## Accessibility

Pass `label` when the skeleton is the only indication that content is loading; screen readers announce it. Omit `label` when a parent component already announces loading, so the announcement is not repeated. The skeleton is then hidden from assistive technology.
