# RowList

`RowList` displays data as actionable rows with aligned leading, metadata and
trailing regions. It uses grid-list semantics and has no column headers.

<Canvas of={Stories.Default} />

## Describe each row

Pass application values through `items` and return a closed
`RowListItemDescriptor` from `getItem`. Each descriptor has a stable `id` and a
visible `label`. It may also include a `description`, `icon`, `badge`, or
`disabled` state. `metadata` accepts text or an ISO calendar date. `value`
accepts text or a currency amount, formatted with the provider locale. A
currency `value` is passed to `Typography`, so a non-finite amount or a
malformed currency code throws a `RangeError` when the row displays its value.

Use the optional `section` object to group rows under structural section
headers. Keep each section ID stable when rows are appended or merged. Keep row
IDs unique and stable so the focused row remains mounted as data changes.

`metadataAmount` adds a second, muted currency cell, such as VAT, between the
metadata and the value. It formats like a currency `value` without a tone.
Each metadata column is reserved only when at least one row in the list uses
it; otherwise the leading region extends towards the value column.

## Summarise a section

Set the section's optional `summary` to end its header with trailing content,
read from the first row in each section. A currency summary takes the same
fields as a currency `value`, shown at the header's 12px size, plus a `label`
that is visually hidden and read before the amount, such as “Confirmed daily
total”. Breeze does not add the amounts up; pass the total with its `tone` and
`sign`. A text summary shows a muted note instead, such as “Not in the balance
yet” for a section that has no total.

## Phone layout

Below Breeze's medium breakpoint the value stays at the end of the row, the
metadata columns are hidden, and a row's badge moves under its description so
the label keeps the full width. Keep anything essential in the label,
description or value.

<Canvas of={Stories.Phone} />

## Show money in and out

Currency values use the compact `amount` role in the default ink tone. Set
`tone: 'positive'` on money in and `sign: 'always'` to show an explicit `+` or
true minus; `sign` follows `Typography`. Set the row's `direction` to `in` or
`out` to give its icon tile the positive or strong wash, and pair it with the
`incoming` or `outgoing` icon. Without `direction` the tile is neutral. Colour
is never the only signal: the sign and icon also carry the direction.

## Activate rows

`onAction` receives the activated row's application item from `items`, as
`Select`, `ComboBox` and `ToggleGroup` do. React Aria supplies the
grid-list keyboard interaction; use the arrow keys to move between rows and
Enter or Space to activate the focused row.

## Loading and empty results

Set the top-level `loading` flag while fetching initial data or refreshing. An
empty grid shows three quiet skeleton rows and one loading announcement. A
populated grid keeps its rows and focus while loading, with the announcement
outside the grid.

Completed empty results display the provider-localized “No items to display.”
message inside the structural grid row and cell. The single persistent polite
status announces the same message.

<Canvas of={Stories.Empty} />

`RowListItemDescriptor.loading` only replaces a row's optional metadata and
value with quiet placeholders; its label, description, icon, badge, and action
remain. The Loading example shows this state alongside a separately busy named
pagination button.

<Canvas of={Stories.Loading} />

Pass a named `loadMore` action when another page is available. Its button keeps
its label while busy, and its status shares the single live loading message
without re-announcing existing rows.
