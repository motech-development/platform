# RowList

`RowList` displays data as a list of rows that people can act on, such as
transactions or documents. Each row has a leading label, optional metadata and
a trailing value, aligned in columns across the list. The list has no column
headers.

<Canvas of={Stories.Default} />

## Row content

Pass your data as `items` and a `getItem` function that returns a
`RowListItemDescriptor` for each item:

- `id` and `label` are required. Keep each `id` unique and stable, so the
  focused row stays in place when the data changes.
- `description`, `icon`, `badge` and `disabled` are optional.
- `metadata` takes text or an ISO calendar date.
- `value` takes text or a currency amount, formatted in the provider's locale.
  A currency `value` is formatted by `Typography`, so a non-finite amount or a
  malformed currency code throws a `RangeError` when the row is displayed.
- `metadataAmount` adds a second, muted currency column, such as VAT, between
  the metadata and the value. It is formatted like a currency `value`, without
  `tone`.

A metadata or value column takes up space only when at least one row in the
list uses it; otherwise the label extends into that space.

## Sections

Give rows a `section` object to group them under section headers. Keep each
section `id` stable when rows are added or merged.

Set the section's optional `summary` to show content at the end of its header.
The summary is read from the first row in each section:

- A currency summary takes the same fields as a currency `value`, shown at the
  header's 12px size, plus a `label` that screen readers announce before the
  amount, such as “Confirmed daily total”. The list does not add up the amounts
  for you; pass the total with its `tone` and `sign`.
- A text summary shows a muted note instead, such as “Not in the balance yet”
  for a section without a total.

## Money in and out

Currency values use the compact `amount` role from `Typography`, in the
default text colour. For money in, set `tone: 'positive'` and `sign: 'always'`
to show an explicit `+`; negative amounts use a true minus sign. `sign` works as
it does in `Typography`.

Set a row's `direction` to `in` or `out` to colour its icon tile for money in
or out, and pair it with the `incoming` or `outgoing` icon. Without
`direction`, the tile is neutral. Colour is never the only signal: the sign and
icon also show the direction.

## Phone layout

Below the `md` breakpoint, the value stays at the end of the row, the metadata
columns are hidden, and a row's badge moves under its description so the label
keeps the full width. Keep anything essential in the label, description or
value.

<Canvas of={Stories.Phone} />

## Row actions

Each row is an action, not a selection: the list keeps no selection state.
Activating a row calls `onAction` with that row's item from `items`.

## Loading

Set `loading` while fetching the first page of data or refreshing it:

- An empty list shows three placeholder rows, and screen readers hear a single
  loading announcement.
- A list that already has rows keeps them, along with the focused row, while
  loading.

<Canvas of={Stories.InitialLoading} />

<Canvas of={Stories.RetainedLoading} />

To show that a single row is still loading, set `loading` in its
`RowListItemDescriptor`. Its metadata and value are replaced with placeholders,
while its label, description, icon, badge and action stay available. This
example also shows a busy Load more button.

<Canvas of={Stories.Loading} />

### Loading more rows

Pass `loadMore` with a `label`, `onAction` and optional `loading` when another
page of data is available. The button keeps its label while busy, and screen
readers hear the same loading announcement as the list, without the existing
rows being read again.

## Empty list

When loading finishes with no rows, the list shows the provider's “No items to
display.” message, and screen readers announce it.

<Canvas of={Stories.Empty} />

## Accessibility

Give the list an `aria-label`, which is required. The list is a single Tab
stop: use the arrow keys to move between rows, and Enter to activate the
focused row. Screen readers announce loading and empty states once,
through a single status message.
