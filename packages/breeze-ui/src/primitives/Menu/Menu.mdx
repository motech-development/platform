# Menu

`Menu` keeps related actions together under a labelled button. Use it for
secondary actions, such as account settings, that should stay out of the main
page until needed.

<Canvas of={Stories.Default} />

## Define actions

Pass your application values in `items`. Use `getItem` to provide each value's
`ItemDescriptor`: `id` and `label` are required, while `description`, `icon`,
`badge` and `disabled` are optional. Give each item a unique `id` within the
menu. Keep labels concise; use descriptions for a short explanation and icons
when they help people scan the choices.

## Respond to a selection

`onAction` receives the selected item's `ItemDescriptor`. The menu closes when
an action is selected. Show action progress, confirmation or errors in the page
or dialog that follows.

Use `defaultOpen` when the menu manages its own visibility. To control
visibility, provide `open` and `onOpenChange` together.

<Canvas of={Stories.Controlled} />

## Keyboard use

Open the menu with the trigger button, Enter, Space or ArrowDown. Use the arrow
keys to move through enabled actions; type a label to jump to a matching action.
Enter or Space selects the focused action. Escape closes the menu and returns
focus to its trigger.
