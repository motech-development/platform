# DatePicker

`DatePicker` is a form field for choosing a date from a calendar. The field shows the selected date in the provider locale's long format, and opens the calendar when activated. Values are ISO `YYYY-MM-DD` strings.

<Canvas of={Stories.Default} />

When no date is selected, the field shows `placeholder`, or the provider's `selectDate` message if you omit it.

## Today

The calendar has a **Today** button that selects the current date, reports it through `onChange` and closes the calendar.

<Canvas of={Stories.TodayAction} />

## Validation

Set `error` to a non-empty message to show it and mark the field invalid.

<Canvas of={Stories.Error} />

## Disabled

Set `disabled` to prevent interaction. A disabled date is not included in form submission.

<Canvas of={Stories.Disabled} />

## Read only

Set `readOnly` to show a recorded date that cannot be changed, for example in a view mode. The field stays focusable and the date is included in form submission, but the calendar does not open.

<Canvas of={Stories.ReadOnly} />

## Optional dates

Unlike other fields, `DatePicker` is required by default, and a required date cannot be cleared.

Set `required={false}` to make the date optional. The calendar then shows a clear button beside **Today**, which empties the field, closes the calendar and reports `null`. The clear button is unavailable while the field is empty.

With an optional date, `onChange` must accept `null`, and an uncontrolled field can start from `defaultValue={null}`. TypeScript rejects both on a required date.

<Canvas of={Stories.Optional} />

## Loading

Set `loading` while the date is unavailable. The label, field and supporting text are replaced by placeholders, the provider's loading message is announced, and the field cannot be used or submitted until loading ends. Errors are hidden and an open calendar closes; the selected value is kept.

<Canvas of={Stories.Loading} />

## Controlled values

Pass `value` and `onChange` to control the field. Set `value` to `null` for an empty field.

For an uncontrolled field, use `defaultValue` with an optional `onChange`. Controlled and uncontrolled props cannot be combined. An uncontrolled field returns to `defaultValue` when its form is reset.

<Canvas of={Stories.Controlled} />

## Forms

Set `name` to include the date in form submission as an ISO string; an empty field submits an empty string. There is no `autoComplete` prop, as browser autofill does not apply to the date button.

## Localisation

Override the provider's `selectDate`, `today`, `clearDate` and `required` messages to translate the placeholder, the **Today** and clear buttons, and the required announcement. Untranslated messages are in English and marked as `en-GB` for screen readers.

## Accessibility

- The visible label names the field, which announces whether it is required or invalid.
- The calendar supports keyboard navigation and announces dates in the provider locale.
- On touch devices, controls have a minimum 44px target.
