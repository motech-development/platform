# DatePicker

`DatePicker` opens a calendar from a button showing the selected date in the
provider locale's long form. The calendar glyph stays at the far edge of the
trigger. The value and callback use ISO `YYYY-MM-DD` strings.

When the field is empty, `placeholder` overrides the provider's `selectDate`
message. Without either override, the English fallback is marked `en-GB` for
assistive technology. `loading` replaces the label, trigger and supporting text
with shape-preserving skeletons, announces the provider loading message, and
disables interaction and form submission until loading clears. The selected
value is retained.

## States

Use `error` to display validation feedback and `disabled` to prevent interaction.
`readOnly` keeps the trigger focusable and the date in form submission, but the
calendar cannot be opened, so the date cannot change; use it to show a recorded
date in view mode. A disabled date is omitted from form submission. Use
`loading` while the field's date is unavailable; errors are hidden and an open
calendar closes while loading.

Unlike the other fields, whose `required` defaults to `false`, `DatePicker`
defaults to `required`. This is a deliberate exception: the dates Breeze
applications record are non-null, so an empty date is not a state worth
offering. A required date does not provide a clear control.

Set `required={false}` for an optional date. Its calendar then shows a clear
control, labelled by the provider's `clearDate` message, which empties the
field, closes the calendar and reports `null`. The control is unavailable while
the field is empty. An optional `onChange` must accept `null`, and an optional
uncontrolled field may start from a `null` `defaultValue`; TypeScript rejects
either on a required date.

There is no `autoComplete` prop. The trigger is a button, not a text input, so
browser autofill has nothing to fill.

## Controlled values

Provide both `value` and `onChange` for controlled usage. Set `value` to `null`
for an empty controlled selection. Use `defaultValue` and an optional `onChange`
for uncontrolled usage; the two forms cannot be mixed, whether the date is
required or optional. An uncontrolled date returns to `defaultValue` when its
owning form resets. With a `name`, the selected ISO date is included in form
submission; an empty value submits an empty string. Override the provider's `required` and `clearDate` messages to
localize the required announcement and the clear control.

## Accessibility

The visible label names the trigger, which exposes required and invalid state.
The calendar supports keyboard navigation and localized date names. Coarse-pointer
targets have a minimum 44px width and height.
