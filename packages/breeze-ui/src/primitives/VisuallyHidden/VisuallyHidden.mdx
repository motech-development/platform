# VisuallyHidden

`VisuallyHidden` hides its content visually while keeping it available to screen readers. Use it for text that sighted users get from a visual cue instead, such as the name of an icon-only control.

<Canvas of={Stories.IconLabel} />

## Accessibility

Do not use it to hide focusable content, such as links or buttons, or information that sighted users also need.
