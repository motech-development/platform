# Select

`Select` lets people choose one option from a fixed list, shown in a popover
when they press the field. It works with browser forms and autofill.

<Canvas of={Stories.Default} />

## Options

Pass your data as `items` and a `getItem` function that describes each item.
`getItem` returns an `ItemDescriptor`:

- `id` and `label` are required.
- `description`, `icon`, `badge` and `disabled` are optional.

Options show only this content; you cannot pass custom JSX, class names or
styles.

<Canvas of={Stories.Description} />

## Selected badge

When the selected item has a badge, the field shows it after the label. Screen
readers announce the badge as part of the value, as they do for the option.

<Canvas of={Stories.SelectedBadge} />

## States

`required`, `disabled` and `readOnly` behave as they do on a native form
control. Pass a non-empty `error` to mark the field invalid and show the
message; there is no separate `invalid` prop.

Set `loading` while the value is not yet available. The field keeps its shape
and cannot be changed until loading ends.

## Controlled

To control the value, pass both `value` and `onChange`. `onChange` receives the
selected item from `items`, or `null`, not a DOM event. For an uncontrolled
field, pass `defaultValue` and optionally `onChange`. Controlled and
uncontrolled props cannot be combined.

<Canvas of={Stories.Controlled} />

## Accessibility

The visible label names the field, and screen readers announce the description
and any error with it. The list can be opened and an option chosen entirely
with the keyboard, and focus moves between the field and the list
automatically.
