# Separator

`Separator` draws a thin line between related regions, such as sections of a panel. It is horizontal by default.

<Canvas of={Stories.Horizontal} />

## Vertical separators

Set `orientation="vertical"` to divide items in a row. Place the separator directly inside an `Inline`, or as a `Grid` item, between the regions it divides. It stretches to the full height of the row, even when the `Inline` centres its other items.

A vertical separator needs a row to take its height from, so it is not visible outside an `Inline` or `Grid`.

<Canvas of={Stories.Vertical} />

## Accessibility

Screen readers recognise the line as a separator and are told its orientation.
