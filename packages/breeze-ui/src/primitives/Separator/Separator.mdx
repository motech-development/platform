# Separator

`Separator` draws the one-token line used between related regions.

<Canvas of={Stories.Horizontal} />

## Vertical separators

A vertical separator stretches to the height of its row. Place it directly inside an `Inline`, or as a `Grid` item, between the regions it divides; it overrides the row's alignment, so the default centred `Inline` still produces a full-height divider. Outside a flex or grid row it has no height.

<Canvas of={Stories.Vertical} />

## Accessibility

The component exposes `role="separator"` and the selected orientation.
