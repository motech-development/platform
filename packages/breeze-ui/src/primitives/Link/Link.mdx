# Link

`Link` is a standalone text link without an underline, such as a View all link in a panel header. It renders a native anchor, so `href` works as usual: keyboard access, opening in a new tab and copying the address all behave as people expect. For an action that does not navigate, use a quiet `Button` instead.

Without a router, the link uses the browser's normal navigation. With a router configured on `BreezeProvider`, same-origin links navigate through the router instead.

## Router navigation

Pass a `router` to `BreezeProvider` when links should change the page without a full reload. `Link` sends the destination and its optional `transitionTypes` to the router, which decides whether to use a browser view transition; see <a href="./?path=/docs/guides-04-motion--docs" target="_top">Motion</a>.

```tsx
<BreezeProvider locale="en-GB" router={router}>
  <Link href="/accounts/transactions" transitionTypes={['nav', 'list']}>
    Transactions
  </Link>
</BreezeProvider>
```

<Canvas of={Stories.RouterNavigation} />

The link calls `router.navigate(path, { transitionTypes })`. `transitionTypes` defaults to an empty list, so an existing `navigate(href)` function that takes one argument works unchanged.

The router receives the path the browser would navigate to, not the raw `href`: a root-relative path including any query string. Relative values such as `accounts`, `../reports` or `?page=2` are resolved against the current page first, so on `/accounts/transactions/`, `href="?page=2"` navigates to `/accounts/transactions/?page=2`.

The path already includes any base path your application is served under. **If your router adds its own `basename`, remove the base from the path before navigating**, or it will appear twice.

### When the browser navigates instead

The router handles only a plain primary click on a same-origin HTTP or HTTPS link. The browser navigates as normal for external links, downloads, links with a `target` other than `_self`, links containing a `#` fragment, and clicks with a modifier key, such as Ctrl or Cmd to open a new tab.

## Variants

The default link uses the brand text colour. Set `variant="subtle"` for a lower-emphasis link.

## Accessibility

A `Link` is distinguished from text by colour alone, so place it on its own rather than inside a sentence. On touch devices and below the `md` breakpoint, it has a minimum height of 44px.

Screen readers announce the link's text as its name. Use `aria-label` or `aria-labelledby` when the text does not describe the destination, and `aria-current` when the link points to the current page.
